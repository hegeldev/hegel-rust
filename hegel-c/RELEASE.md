RELEASE_TYPE: patch

This patch fixes the recursion protocol generating far smaller values than the leaf budget allows for branch functions averaging fewer than two children per branch (for example an expression grammar with more unary than binary operators). Branch decisions were priced as if every branch had exactly two children; with mean arity below two the induced branching process was firmly subcritical, values collapsed to a handful of nodes, and — since the leaf budget was never hit — the retry path never corrected anything.

The engine now observes each branch's arity as generation closes it and reprices branch decisions from that evidence, and a new `hegel_recursion_finish` call completes the protocol for each value: the engine checks the finished value's arities against the price its attempt started from and reports `HEGEL_E_RETRY` when the attempt was mispriced, in which case the client drops the value and regenerates it from the root at the corrected price (at most twice per draw). Branch functions that always produce two children confirm the starting price at every branch, so their distributions are unchanged, and values containing no branches are always accepted, so small values stay exactly as common. Grammars whose branches cannot grow the leaf count at all (unary-only chains) now price up to a capped probability of 0.95, spreading chain lengths up to the depth limit instead of ending almost immediately. Clients that never call `hegel_recursion_finish` keep the previous accept-everything behavior.
