RELEASE_TYPE: patch

This patch adds the fuzzer client: a set of `HEGEL_FUZZ_*` environment variables, read at `hegel_run_start`, through which an external fuzzer drives a run one test case at a time. `HEGEL_FUZZ_OUTPUT` makes the run execute exactly one test case — replaying the choice-sequence prefix in `HEGEL_FUZZ_PREFIX` and drawing randomly past its end — and write a JSON record of it: status, origin, every choice with its constraint, spans, events, targets, and the choice sequence in the database entry format for feeding back as the next prefix. `HEGEL_FUZZ_REPRODUCE` replays a prefix like a database entry, shrinking and persisting the failure it reproduces, `HEGEL_FUZZ_TRACE` streams each choice to a file as it is drawn so a case that kills the process still leaves its sequence behind, and `HEGEL_FUZZ_TEST` selects the database key the variables are for. The `hegel_run_start` documentation describes them.
