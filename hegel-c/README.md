# hegeltest-c

C-ABI bindings for [hegel](https://hegel.dev)'s native property-based
testing engine. The build artefacts are shared and static libraries plus a
checked-in C header at
`include/hegel.h` (generated by `cbindgen` from `src/lib.rs`).

**This crate is published mostly to reserve the name on crates.io.**
If you want to *use* libhegel from a non-Rust language, you almost
certainly want the prebuilt libraries + header from a GitHub release
rather than building this crate yourself:

> <https://github.com/hegeldev/hegel-rust/releases>

Each release publishes shared and static
`libhegel-<goos>-<goarch>.<ext>` libraries, `hegel.h`, and matching
`.sha256` sidecars for `linux/amd64`, `linux/arm64`, `darwin/arm64`,
`windows/amd64`, and `windows/arm64`. Intel macOS (`darwin/amd64`) is not
published; build the crate yourself if you need it.
