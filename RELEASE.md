RELEASE_TYPE: patch

This patch makes every draw open a span around the generator it runs. `TestCase::draw`, `draw_silent`, `draw_named` and `draw_and_print` now run the generator inside a span labelled with its `Generator::label`, closed when the draw returns. Previously only Hegel's own combinators opened spans, each by hand inside its `do_draw`, so a hand-written `Generator` that drew several values got no span grouping them, its `label` was never consulted, and the shrinker could not treat its values as units (delete one from a `vecs` of them, swap two of them, or replace a value with a nested one of the same kind). Every generator now gets the same treatment whether it is Hegel's or yours.

Generators built from other generators should draw their components through `tc.draw_silent(&component)` (or `tc.draw_and_print` when printing) rather than calling `component.do_draw(tc)` directly, so each component's choices get a span of their own; the built-in combinators and the `#[composite]`, `#[derive(DefaultGenerator)]` and `compose!` macros already do. A generator that opened its own span around its whole `do_draw` no longer needs to, and should stop, since that span is now opened for it. Nested `tc.draw` calls made from inside a generator drawn with `draw_silent` are, like those inside a combinator, no longer reported as top-level draws in the failing-example output.
