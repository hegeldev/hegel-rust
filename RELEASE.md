RELEASE_TYPE: patch

This patch adds the fuzzer client: a set of `HEGEL_FUZZ_*` environment variables through which an external fuzzer — one that chooses each test case from what earlier ones did, rather than generating them independently — drives a test program one execution at a time. They work for every entry point, `#[hegel::main]` binaries and `#[hegel::test]` functions alike.

When `HEGEL_FUZZ_OUTPUT` names a file, the run executes exactly one test case and writes a JSON record of it there: its status and failure origin, every choice it made with the constraint it was drawn under, its spans, events and targets, and the choice sequence encoded for feeding back through `HEGEL_FUZZ_PREFIX`, which the next case replays as a prefix before drawing randomly past its end. `HEGEL_FUZZ_REPRODUCE` replays a prefix the ordinary way instead, shrinking and persisting the failure it reproduces so the test's normal runs replay it from then on, `HEGEL_FUZZ_TRACE` streams each choice to a file as it is drawn so a case that kills the process still leaves its sequence behind, and `HEGEL_FUZZ_TEST` selects which test of a process the variables are for. The settings documentation describes the record and the variables in full.

It also adds `HEGEL_STATEFUL_STEPS`, which replaces every state machine's step count for the run (whatever `Machine::steps` set), so a suite's stateful tests can be driven deeper, as a fuzzer wants, without editing source. The variable must be a positive integer; anything else is a usage error.

For a fuzzer that shrinks by replaying candidates itself, `HEGEL_FUZZ_TAIL=none` makes the one test case draw nothing past its prefix, overrunning instead and punning a misfit as the engine's shrinker does, and the record carries `realized_base64`, the case's choices with their constraints and its spans. The internal `fuzz-driver` feature of `hegeltest-c` exposes the shrinker, that realized form and the choice serialisers as a Rust API, with a call budget on the shrinker for drivers whose executions are too costly to bound by the clock alone.
